==== Datenbanken
In der KommunalApp kommen zwei Datenbanken zum Einsatz: eine Postgres-Datenbank
für die Prozessverwaltung und -ausführung, sowie eine Mongo-DB-Instanz für die
dokumentbasierte Inhaltspflege.

====== Migrationen

Migrationen werden automatisch beim Start des Backends ausgeführt. Neue
Migrationen können über den Befehl

[source,sh]
----
  dotnet ef migrations create "NameDerMigration" --project API
----

im Backend-Verzeichnis erstellt werden.

====== Migrationen

Es gibt aktuell keinen Bedarf für Migrationen in der Inhaltspflege. Rein
additive Änderungen wie etwa das Hinzufügen von Feldern können ohne Migration
vorgenommen werden; weitreichendere Änderungen wie das Verschieben oder
Umbenennen der Felder würde jedoch eine manuelle Migration erfordern.
